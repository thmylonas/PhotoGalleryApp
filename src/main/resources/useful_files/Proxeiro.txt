The Webflux/WebClient throws the next exception:
    "org.springframework.web.reactive.function.client.WebClientResponseException:
    200 OK from GET https://jsonplaceholder.typicode.com/photos, but response failed with cause:
    org.springframework.core.io.buffer.DataBufferLimitException: Exceeded limit on max bytes to buffer : 262144"

[Not_Working] Solution
--------------------------
Add 1 of the next properties in "application.properties":
- spring.codec.max-in-memory-size=500MB (Deprecated)
- spring.http.codecs.max-in-memory-size=500MB

[Working] Solution
----------------------
Add in the @Configuration class the next bean:

    @Bean(value = "webClient")
    public WebClient webClient() {
        return WebClient
                .builder()
                .codecs(codecs -> codecs
                        .defaultCodecs()
                        .maxInMemorySize(500 * 1024 * 1024)
                )
                .build();
    }
